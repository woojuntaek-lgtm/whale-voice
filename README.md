# 고래의 한 문장

에니어그램 9번 중재자 [Psyche 11] 영상의 부록 앱입니다. 3초 안에 작은 선택을 고르는 30초 결단 게임("아무거나"와 시간 초과는 미룸으로 바다에 안개가 낌), 남에게 묻기 전에 내가 원하는 것을 한 문장으로 적는 연습, "누이 좋고 매부 좋고, 그럼 나는?" 막대, 꿈쩍도 않는 9번에게 건네는 다섯 장의 카드, 실행과 태만 1분 계기판, 그리고 9번 중재자 한눈에(두려움·바람·방어기제·미덕과 악덕·상징·九 안의 十·날개와 화살표·추정 인물·9번과 잘 지내려면)를 담았습니다. 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 결단 30초: 작은 선택 게임, 고래 크기와 미룸(안개)
- ② 내 목소리: 내가 원하는 것 한 문장, 누이·매부·나 막대, 다섯 장의 카드
- ③ 실행 계기판: 10문항, 실행 vs 태만 — 고래가 헤엄치는 쪽
- ④ 9번 중재자: 한눈에 표, 九와 十, 9w1 몽상가·9w8 조정자, 스트레스 6·통합 3, 추정 인물, 잘 지내려면

## 알림
- 내용은 정필 수심명의 저서·특강·강의원고(영상 대본)를 따랐습니다. 게임의 선택지, 카드 뒷면의 실천, 계기판 문항, 막대 그림은 대본을 바탕으로 앱이 만든 것입니다.
- 계기판과 게임은 성찰을 돕는 참고용이며 검사·진단이나 전문 상담을 대신하지 않습니다. 인물은 추정일 뿐입니다.
- 적은 말과 고른 답은 저장하거나 보내지 않습니다.
